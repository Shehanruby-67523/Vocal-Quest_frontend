# 🎙️ Vocal Quest – AI-Driven Accessible Gaming

**Vocal Quest** is an accessible, voice-controlled adventure game that enables hands-free gameplay using natural language commands. Built for people with physical disabilities, visual impairments, or anyone seeking an innovative, inclusive gaming experience.

> *"Play with your voice. Enter the castle. Prove your knowledge."*

---

## ✨ Key Features

- 🎤 **Full Voice Control** – Navigate, choose options, and play using only your voice (Web Speech API).
- ♿ **Universal Accessibility** – High contrast UI, screen reader support, and text-to-speech narration (WCAG 2.1 AA).
- 📖 **Interactive Storytelling** – Branching narrative where your choices matter.
- 🧠 **Quiz Barrier** – Answer 50 general knowledge MCQs to defeat the gatekeeper and enter the castle (pass: 40/50).
- 💾 **Progress & Profile** – User authentication and automatic save/load system.
- 🏆 **Achievements** – Rewards for exploration and different playstyles.

---

## 🕹️ How It Works

1. **Speak** – Use voice commands like *"Start"*, *"Option One"*, *"Continue"*, or *"Repeat"*.
2. **Listen** – The game narrates story and feedback via text-to-speech.
3. **Decide** – Your choices shape the story.
4. **Quiz** – Answer 50 general knowledge questions to unlock the castle.
5. **Progress** – Your game saves automatically at key points.

## 🚀 Getting Started (Frontend Only)

### Prerequisites

- Modern browser (Chrome 70+, Firefox, Edge)
- Microphone (built-in or external)
- Internet connection

### Installation

```bash
# Clone the repository
git clone https://github.com/Shehanruby-67523/Vocal-Quest_frontend.git

# Navigate to project folder
cd Vocal-Quest_frontend

# Install dependencies
npm install

# Run the development server
npm run dev
```
